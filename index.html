RESILIENT DATA LAYER

Local-First Persistence & Conflict Reconciliation

Campus networks frequently experience electricity load shedding or unstable broadband. ASTRIV School Suite operates locally via an embedded client database, logging all ledger transactions, student admissions, and exam marks to local persistent stores with monotonic timestamp tracking.

  • Zero-latency local reads and writes on low-spec hardware
  • Automatic reconnect listener triggering batch delta pushes
  • CRDT-inspired reconciliation to prevent fee ledger overwrites
// Sync Engine: Delta Conflict Resolver
async function reconcileLocalLedger(batch) {
const localDeltas = await db.getUnsyncedRecords();
const response = await fetch('https://astriv.co/api/v1/sync', {
method: 'POST',
body: JSON.stringify({ deviceId, deltas: localDeltas })
});
if (response.status === 200) {
await db.markAsCommitted(response.commitHash);
console.log("[ASTRIV] Edge node synced successfully");
}
}

COMPLIANCE & GOVERNANCE

Double-Entry Fee Tracking & Statutory Ledgers

Institutional corruption and fee discrepancies occur when systems permit arbitrary ledger modifications. ASTRIV enforces immutability: every single fee receipt, tuition concession, and staff payroll transaction is recorded as an immutable double-entry journal.

  • Tamper-resistant transaction ledgers with balance verification
  • Schedule 9230/3000 formatted exports for official institutional filings
  • Strict role isolation: Principal, Accountant, Teacher, and Student registers
-- Institutional Ledger Double-Entry Schema
CREATE TABLE ledger_journal_entries (
entry_id VARCHAR(64) PRIMARY KEY,
campus_id VARCHAR(32) NOT NULL,
debit_account VARCHAR(64) NOT NULL,
credit_account VARCHAR(64) NOT NULL,
amount_cents BIGINT NOT NULL,
verified_by_user VARCHAR(64) NOT NULL,
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
