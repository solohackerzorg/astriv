Deploy Open Core in Minutes

Spin up the local containerized stack or connect the orchestration client to the hosted cloud registry.

# Clone the repository and configure runtime
$ git clone https://github.com/solohackerzorg/astriv.git
$ cd astriv && npm install
# Initialize environment and start orchestration services
$ cp .env.example .env
$ npm run dev
